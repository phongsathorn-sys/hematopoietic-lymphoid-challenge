# Hematopoietic and Lymphoid Systems Quiz

เว็บแอปแบบ Static สำหรับทำแบบทดสอบ 10 ชุด ชุดละ 10 ข้อ รวม 100 ข้อ
เนื้อหาอ้างอิงจากเอกสารประกอบการเรียนเรื่อง Pathophysiology of the Hematopoietic and Lymphoid Systems

## ไฟล์
- `index.html` — หน้าเว็บหลัก
- `style.css` — รูปแบบเว็บ
- `app.js` — ข้อมูลคำถามและ logic ของแบบทดสอบ

## การนำขึ้น GitHub Pages
1. สร้าง GitHub repository ใหม่
2. Upload ไฟล์ทั้ง 3 ไฟล์นี้ไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment** เลือก **Deploy from a branch**
5. เลือก branch `main` และ folder `/ (root)`
6. กด Save
7. รอ GitHub Pages deploy แล้วเปิด URL ของ repository
